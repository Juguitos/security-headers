CORS Misconfiguration — Cross-Origin Resource Sharing
6.5 Medium

Se identificó una configuración insegura de Cross-Origin Resource Sharing (CORS) que podría permitir que sitios externos no autorizados interactúen con recursos de la aplicación desde el navegador de un usuario autenticado.

El riesgo aumenta si el servidor refleja dinámicamente el encabezado Origin, permite orígenes comodín o desconocidos, acepta Origin: null, o combina Access-Control-Allow-Credentials: true con orígenes no controlados. En ese escenario, un atacante podría alojar una página maliciosa y, al lograr que un usuario autenticado la visite, intentar leer respuestas sensibles de la aplicación mediante solicitudes cross-origin.

OWASP indica que Access-Control-Allow-Origin define qué dominios pueden leer respuestas del servidor y que una mala configuración puede exponer información a orígenes no autorizados.

CVSS v3.0: 6.5 · Media
Vector: CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:N/A:N

La severidad puede subir a Alta si se confirma que CORS permite credenciales y expone información sensible de usuarios autenticados (datos personales, tokens, información financiera, sesiones o respuestas administrativas).
